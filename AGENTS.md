# Versioning Policy
You MUST automatically manage the `version` field in `package.json` and any UI version displays for every coding turn. Determine the impact of your changes and update the version accordingly:
- PATCH (e.g., 1.0.1 -> 1.0.2): For bug fixes and minor improvements.
- MINOR (e.g., 1.0.2 -> 1.1.0): For new features without breaking existing functionality.
- MAJOR (e.g., 1.1.0 -> 2.0.0): For major redesigns, breaking changes, or significant architectural shifts.

Always perform this update in the same turn as your code changes.
