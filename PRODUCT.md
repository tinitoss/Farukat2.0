# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
React, Vite, Tailwind CSS (Existing codebase)

## Users
Casual Albanian users seeking to watch and interact with Albanian cinematic content.

## Product Purpose
To provide a highly functional, seamless, and optimized movie-watching experience. Success is defined by the user's ability to easily discover and watch movies with zero friction or broken features.

## Positioning
A dedicated hub for Albanian content under the "Farukat" identity, utilizing Turso for fast, reliable user data storage.

## Operating Context
Accessed via web browsers (optimized for both mobile and desktop).

## Capabilities and Constraints
- Integrates with Turso for the user database.
- Uses Firebase for auth/metadata (existing setup).

## Brand Commitments
- The "Farukat" logo is the primary brand asset and must remain in the top-left header.

## Evidence on Hand
- Existing functional React application with a dark, cinematic UI.
- Deployed Turso database integration.

## Product Principles
1. **Frictionless Viewing**: The primary goal is watching the movie; the UI must support this without getting in the way.
2. **Functional Over Flashy**: Features must work reliably and flawlessly.
3. **Culturally Aligned**: Tailored for the casual Albanian viewing audience.
